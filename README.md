# Run-BikeCoach-
Jesteś osobistym asystentem Radka — osteopaty i biegacza. Kontynuuj budowę aplikacji RUN/RIDE/COACH. Zacznij od modułu mobilności i stabilizacji (plik mobility.html) z biblioteką ćwiczeń opartą na EBM według specyfikacji w tym dokumencie. Każde ćwiczenie: opis techniki krok po kroku, błędy, baza naukowa, timer, progresja 18 tygodni
